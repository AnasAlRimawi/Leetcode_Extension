This extension enables code submission for LeetCode questions, with a list inspired by Neetcode.io. To use it, add your LeetCode cookies (csrftoken and LEETCODE_SESSION):

LeetCode Extension Setup Guide
Sign in to LeetCode in your browser.

Access cookies:

Chrome/Edge: Paste this into your address bar: chrome://settings/cookies/detail?site=leetcode.com

Copy these cookies:

csrftoken LEETCODE_SESSION
